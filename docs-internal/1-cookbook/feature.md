# Cookbooks feature

## Description
This feature list the cookbooks. A cookbook is a group of recipes created by the user.
The recipes will be created later.
A cookbook can have multiple recipes and a recipe can belong to multiple cookbooks.
A cookbook only needs a name.

## Display
The cookbooks are displayed as a grid that can be sorted alphabetically or by date of update.
Pick the latest recipe added for an image
Show the name and the total recipes that it hold as a label.
Check list.jpg and sort.jpg for reference

## Create
To add a cookbook, the user needs to click on the FAB plus button. He can choose between a recipe and a cookbook.
A bottom dialog opens with the name field.
Check add.jpg and add-button.jpg for reference
