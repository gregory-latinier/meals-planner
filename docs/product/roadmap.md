# Product Roadmap

**Last updated**: 2026-09-23

## Now

- Foundation finalized (self-hosted TypeScript + Next.js + Supabase baseline).
- Auth Bootstrap and Local Recovery:
  - First-run setup token
  - Mobile login page
  - Local forgot-password reset flow

## Next

- Weekly meal planning core flow.
- Grocery list generation from planned meals.
- Realtime multi-user grocery list updates.
- PWA installability and mobile UX polish.
- Meal Library v1:
  - Search by meal name and ingredient text
  - Sort by name/created/updated
  - Grid/Table toggle with remembered preference
  - Meal fields: name, recipe, URL, photo
  - Manual async AI extraction (Gemini) for ingredients + per-serving suggested amounts
  - AI admin page for shared token/model configuration

## Later

- Recipe management improvements (import/edit/organization).
- Store-aware list grouping/optimization.
- Optional stronger auth controls (rate limiting, 2FA exploration).
- Enhanced backup verification and restore UX.
